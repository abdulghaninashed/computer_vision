# نظام مراقبة حركة المرور

واجهة الويب مبنية باستخدام HTML وCSS وJavaScript، بينما تبقى معالجة الفيديو والتعرّف على المركبات في Python.

## التشغيل

من مجلد المشروع الرئيسي:

```bash
pip install -r requirements.txt
python src/main.py
```

سيبدأ الخادم على `http://127.0.0.1:5000` ويفتح الصفحة في المتصفح تلقائيًا. اختر ملف فيديو بصيغة MP4 أو AVI أو MOV أو MKV، ويمكن تعديل موضع خط المنتصف من **الإعدادات** قبل بدء التحليل.

بعد عبور المركبات خط العدّ، يعرض زر **التقرير** جدولًا بعدد السيارات والفانات والشاحنات والباصات، وسعر كل مركبة والإجمالي بالدولار: السيارة 1$، الفان 1.5$، الشاحنة 2.5$، والباص 2$.

يمكن إيقاف التتبع مؤقتًا واستئنافه من زر **إيقاف مؤقت**. عند الضغط على **إيقاف**، يعرض النظام تقرير الجلسة ثم يصفّر أعداد جميع المركبات واتجاهاتها بعد انتهاء التتبع.
